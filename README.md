# CRS 涉税金融资产与证券交易盈亏智能核算系统
> **CRS Tax-Compliance Financial Assets & Securities Realized P&L Intelligent Calculator**  
> 专为证券公司投资顾问、私人银行家、财富管理从业者及跨境涉税审计专家量身打造的一站式金融资产与单股盈亏智能穿透核算平台。

---

## 📖 项目简介

在跨境金融资产涉税信息尽职调查（CRS）与高净值客户个人所得税综合申报中，客户在香港及海外券商的投资账单通常跨度长达数年乃至数十年，涵盖大量二级市场买卖、实物红股分派、供股配股认购、私有化退市收购、代码转换转仓以及复杂的双边佣金印花税等费用。

人工比对结单不仅耗时耗力，而且极易因换码、实物分派或费用计算失误导致申报数据出现偏差。

**本项目提供了一套完全运行在浏览器本地安全沙箱环境中的智能核算引擎**，只需将券商系统导出的流水文件（CSV / Excel）拖入页面，即可在毫秒级内完成全生命周期的成本结转与指标核算，一键生成符合 OECD 准则与税法要求的申报报表。

---

## 🌟 核心功能特性

### 1. 📊 CRS 四大核心涉税指标看板
系统自动汇总任意统计周期或全历史生命周期的四大关键申报数据，点击任意卡片即可平滑定位至对应分类明细：
- **股息总额（Gross Dividends）**：精准汇总全周期现金分红与境外代扣税明细；
- **利息总额（Gross Interest）**：准确识别并汇总各币种现金账户结息与存款利息；
- **股票已实现盈亏（Realized P&L / Capital Gains）**：扣除双边全部佣金与交易税费后的真实净收益；
- **卖出交易总交收回款（Total Gross Proceeds）**：券商系统实际交收回款总额。

---

### 2. 🧮 双计税成本核算引擎（实时无缝切换）
- **移动加权平均成本法（WAC - Weighted Average Cost）**：国内个税及企业所得税最主流的加权平均成本核算标准；
- **先进先出法（FIFO - First-In, First-Out）**：欧美及多国税务居民申报首选的税法结转标准；
- 支持在界面右上角一键毫秒级切换，所有历史交易结转成本与已实现盈亏实时动态重算。

---

### 3. 🔍 股票全景总览与全生命周期单股穿透明细
- **持仓全景透视**：清晰展示全部、持仓中、已清仓股票的代码、英文名称、交易市场、累计买卖股数、买入总金额、卖出总金额及已实现盈亏；
- **逐笔穿透弹窗（Drill-Down Modal）**：点击任一股票名称或穿透按钮，即可调出该股票全生命周期逐笔交易流水：
  - 精确呈现每笔交易的**撮合成交单价**、**交收金额（`dr_amount` / `cr_amount`，含佣金税费）**、**已实现净盈亏**、**结后持仓量**与**结后持仓均价**；
  - 配备专属业务标签：`买入`、`卖出`、`🎁 红股获派`、`供股配股`、`📥 证券转入`，并附带券商原始业务说明备注。

---

### 4. 🧠 复杂上市公司行动与特殊业务智能识别
针对券商流水中的非标准交易形态，系统内置深度专家规则库：
- **实物分红 / 红股获派（Bonus Shares / Scrip Dividend）**：
  - 如腾讯派发美团（03690）实物股票，自动识别为 `🎁 红股获派`，计税成本精准确认为 `0.00`，卖出时全额计入资本利得，并在备注列清晰指明分红出处；
- **私有化退市现金收购（Privatisation / Takeover）**：
  - 自动跨记录将股份注销出账与现金流水中的私有化收购回款进行关联匹配，恢复真实卖出处置回款与真实盈利；
- **供股认购与换码对冲（Rights Issue & Code Conversion）**：
  - 自动关联供股认购扣款，并彻底过滤系统内部代码转换（如临时代码 `*02349` 转换为 `02349`）产生的无金额转出，彻底根除虚假卖出与虚假亏损；
- **全税费费用闭环（Transaction Fees & Commissions）**：
  - 100% 严格直接使用 CSV 原生 `dr_amount`（买入净支出，已包含佣金税费）与 `cr_amount`（卖出净回款，已扣除佣金税费），确保算出的已实现盈亏与银行/券商资金变动绝对吻合。

---

### 5. ⚠️ 期初存量股票智能识别与成本补录引擎
- **自动检测局部截断流水**：当导入的流水未包含客户早年开仓记录时，系统自动识别并标记为 `⚠️ 期初存量股票`；
- **一键补录开仓均价**：投顾可在弹窗内直接填入已知的历史买入均价，系统自动注入期初建仓记录并实时重算净盈亏与收益率。

---

### 6. 📈 实时持仓市值与未实现浮动盈亏测算
- 针对持仓中的股票，提供**行内最新市价快速录入与修改**；
- 实时联动计算持仓总市值、未实现浮动盈亏（Unrealized P&L）及浮动回报率（ROI%）；
- 严格遵循中文金融界**红涨（Gain）绿跌（Loss）**的专业视觉规范。

---

### 7. 📅 历年申报表与由新到旧时光轴
- 顶部年份胶囊切换栏与历年申报汇总表统一采用**由新到旧（最新年份在最前）**排序；
- 支持一键按年过滤申报周期，亦支持精准自定义日历区间。

---

### 8. 📄 多格式导出与打印
- **导出标准申报 Excel**：一键生成排版工整的多 Sheet 申报工作簿；
- **PDF / 打印就绪**：内置专业 Print 样式，自动隐藏操作控件，可一键打印或导出为高管汇报级 PDF 账单。

## 📂 文件格式与导入规范

系统内置健壮的 **RFC 4180 标准 CSV 行解析器**（完美支持字段内包含英文逗号、换行和双引号转义）及原生 Excel 解析能力，支持主流券商标准流水（如招商证券国际、富途、老虎、中银国际、华泰国际等导出的交易与资金往来流水）。

### 官方标准导入模板字段（27 列）：
| 字段名 | 说明 |
| :--- | :--- |
| `account_no` | 客户证券账号 |
| `account_name_chi` / `account_name_eng` | 客户中文/英文姓名 |
| `trade_date` | 交易或入账日期（支持 `YYYY-MM-DD` 或 `DD-Mon-YYYY` 等格式） |
| `record_type` | 业务类型（如 `Trade`、`Cash In/Out`、`Product In/Out` 等） |
| `io_type` | 收付方向（`B` 买入、`S` 卖出、`D` 存入、`W` 提取） |
| `product_code` | 股票/产品代码（如 `00700`、`03690`） |
| `product_name` | 股票/产品原生英文名称 |
| `qty` | 交易股数 |
| `average_price` | 撮合成交单价 |
| `ccy` | 结算币种（如 `HKD`、`USD`、`RMB`） |
| `dr_amount` | 扣除金额 / 交收净支出（含佣金及全部第三方税费） |
| `cr_amount` | 存入金额 / 交收净回款（已扣除佣金及税费） |
| `remark` | 券商原始业务备注与公司行动说明 |

> 页面顶部提供了 **「📄 下载空白模板 (CSV)」** 按钮，可直接获取纯净标准模板。
